# Video Unicalizer на Mac

В архиве лежат исходники и скрипты сборки. Готового `.app` внутри нет:
приложение для macOS невозможно собрать на Windows, где всё это готовилось.
Зато сборка на самом Mac делается двумя двойными кликами.

---

## Что поставить заранее

**ffmpeg** — без него программа не сможет обрабатывать видео.

Если есть Homebrew:

```bash
brew install ffmpeg
```

Если Homebrew нет, сначала он:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

Проверить, что встало:

```bash
ffmpeg -version
```

**Python 3.10 или новее.** На свежих macOS он уже есть. Проверить:

```bash
python3 --version
```

Если нет — `brew install python`.

---

## Разрешить запуск скриптов

macOS не сохраняет права на запуск внутри zip-архивов, поэтому один раз
выполните в Терминале (перетащите папку `mac` в окно Терминала после `cd `,
чтобы не набирать путь):

```bash
chmod +x "путь/до/папки/mac/"*.command
```

## Дальше два пути

### Просто попробовать

Двойной клик по **`Запуск без сборки.command`**.

Первый запуск займёт пару минут — ставятся библиотеки. Дальше открывается сразу.

### Собрать нормальное приложение

Двойной клик по **`Собрать приложение.command`**.

Через несколько минут появится `dist/Video Unicalizer.app` — обычное
приложение с иконкой, его можно перетащить в «Программы».

При первом открытии macOS скажет, что разработчик неизвестен (подписи Apple
у сборки нет). Обходится так: правый клик по приложению → **Открыть** →
в диалоге ещё раз **Открыть**. Дальше запускается как обычно.

## Отличия от версии для Windows

Никаких — движок один и тот же. Разница только в кодировании:

| | Windows (у вас) | Mac |
|---|---|---|
| Ускорение | NVENC на видеокарте | видеокарта Apple через VideoToolbox не задействована |
| Кодировщик | `auto` берёт NVENC | `auto` возьмёт процессор (x264) |

На Mac ставьте кодировщик **cpu** и не поднимайте «Параллельных задач» выше
числа ядер. На Apple Silicon x264 работает быстро, но всё же медленнее, чем
NVENC на вашей RTX.

## Если приложение не запускается

**«Команду не удалось выполнить»** — не выданы права на запуск,
вернитесь к шагу `chmod +x`.

**«Python was not found»** — не установлен python3, поставьте `brew install python`.

**Программа открылась, но пишет «Не найден ffmpeg»** — `brew install ffmpeg`,
затем перезапустите.

**Сборка падает на PySide6** — на очень старых macOS (ниже 11) PySide6 не
ставится. Тогда остаётся консольный режим:

```bash
python3 -m unicalizer.cli -i ~/Movies/исходники -o ~/Movies/готовое -n 5 --preset medium
```
